# Tkinter Projects

This repository contains simple Python GUI projects created using the Tkinter library. These projects help beginners understand how to build graphical user interface (GUI) applications in Python.

## Projects in this Repository

### 1. File Explorer

A simple file explorer application built with Tkinter.
It allows users to browse and open files from their system using a graphical interface.

Features:

* Browse system files and folders
* Open selected files
* Simple and user-friendly interface

### 2. To-Do List

A basic To-Do List application built using Tkinter.
It helps users manage daily tasks easily.

Features:

* Add new tasks
* Delete completed tasks
* Simple task management interface

## Technologies Used

* Python
* Tkinter (Python GUI Library)

These projects are created for learning and practicing Python GUI development using Tkinter.
